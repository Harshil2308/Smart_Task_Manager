Slide 3 - Technical Approach

Overview:
- We implemented a hybrid intelligent task management system
- Priority is not decided by one fixed rule
- The system combines ML prediction, keyword overrides, deadlines, effort, impact, workload, and live status updates

Working Flow:
1. Manager logs in or registers
2. Manager creates a task manually or through voice input
3. Backend extracts task details and deadline information
4. Backend sends task factors to the Flask ML service
5. ML service predicts priority score and priority label
6. Backend applies keyword-based overrides using reference keywords from MySQL
7. Final task data is stored in MySQL
8. Employee views tasks in priority-wise grouped sections
9. Employee updates status
10. Dashboards reflect workload, completion, and alerts

System Architecture:
Frontend (HTML/CSS/JS)
-> Backend API (Node.js + Express)
-> MySQL Database
-> ML Service (Python Flask)

Key Implemented Features:
- Authentication with manager and employee roles
- Task creation and assignment
- Voice-to-task capture
- ML-based priority scoring
- Keyword-based priority enhancement
- Priority-wise employee task view
- Overdue and approaching-deadline alerts
- Manager workload visibility
- Completion tracking
- Profile update support

What makes this project different:
- Hybrid intelligence model:
  ML prediction + keyword override engine
- Voice-based task creation for faster input
- Employee dashboard grouped by task priority
- Daily prioritized view and deadline alerts
- Manager dashboard with workload and completion visibility

Unique implementation detail:
- A task like "urgent client meeting tomorrow" is not treated as plain text only
